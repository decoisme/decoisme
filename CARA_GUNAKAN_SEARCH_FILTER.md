# Cara Menggunakan Search & Filter Blog

## 🔍 Panduan Cepat

Fitur pencarian dan filter untuk menemukan blog post dengan cepat.

---

## 1️⃣ SEARCH (Pencarian)

### Cara Menggunakan
```
┌────────────────────────────────┐
│ 🔍 SEARCH POSTS...         [X] │
└────────────────────────────────┘
```

1. Ketik keyword di kotak search
2. Hasil langsung muncul (real-time)
3. Klik [X] untuk clear search

### Apa yang Bisa Dicari?
- ✅ **Judul post** - Contoh: "nextjs"
- ✅ **Deskripsi post** - Contoh: "tutorial"
- ✅ **Tags** - Contoh: "design"

### Contoh
- Ketik: `nextjs` → Semua post tentang Next.js
- Ketik: `tutorial` → Semua tutorial
- Ketik: `ui` → Post dengan tag #ui

---

## 2️⃣ FILTERS (Advanced)

### Cara Membuka
```
[ 🔧 FILTERS ]  ← Klik tombol ini
```

Panel filter akan slide open dari atas.

---

## 3️⃣ CATEGORY FILTER

### Tampilan
```
[ALL] [DESIGN] [CODE] [TUTORIAL]
```

### Cara Menggunakan
1. Klik category yang diinginkan
2. Hanya post dari category tersebut yang muncul
3. Klik [ALL] untuk reset

### Contoh
- Klik `[DESIGN]` → Hanya post design
- Klik `[CODE]` → Hanya post code
- Klik `[ALL]` → Semua post

---

## 4️⃣ DATE RANGE FILTER

### Tampilan
```
DATE RANGE //
[ALL TIME] [LAST WEEK] [LAST MONTH] [LAST YEAR]
```

### Cara Menggunakan
1. Klik tombol date range
2. Post difilter berdasarkan tanggal publish

### Contoh
- `[LAST WEEK]` → Post 7 hari terakhir
- `[LAST MONTH]` → Post 30 hari terakhir
- `[LAST YEAR]` → Post 365 hari terakhir
- `[ALL TIME]` → Semua post (default)

---

## 5️⃣ TAGS FILTER

### Tampilan
```
TAGS // (2)
#nextjs  #design  #tutorial  #react  #css
#javascript  #ui  #ux  #webdev
```

### Cara Menggunakan
1. Klik tag yang diinginkan
2. Bisa pilih **multiple tags** (lebih dari 1)
3. Post dengan tag tersebut akan muncul

### Contoh
- Klik `#nextjs` → Post dengan tag nextjs
- Klik `#design` + `#ui` → Post dengan tag design ATAU ui
- Klik lagi untuk unselect

---

## 6️⃣ RESULTS COUNTER

### Tampilan
```
[12 RESULTS]  [✕ CLEAR ALL]
```

### Info
- **12 RESULTS** = Jumlah post yang ditemukan
- **CLEAR ALL** = Reset semua filter

---

## 7️⃣ ACTIVE FILTERS DISPLAY

### Tampilan
```
Search: "nextjs"  #design [X]  #ui [X]
```

### Cara Menggunakan
- Lihat filter yang aktif
- Klik `[X]` untuk remove individual filter
- Klik `CLEAR ALL` untuk remove semua

---

## 8️⃣ KOMBINASI FILTER

### Contoh 1: Search + Category
```
Search: "tutorial"
Category: [CODE]
→ Hasil: Tutorial coding saja
```

### Contoh 2: Category + Date
```
Category: [DESIGN]
Date: [LAST WEEK]
→ Hasil: Post design 7 hari terakhir
```

### Contoh 3: Search + Tags
```
Search: "react"
Tags: #nextjs, #tutorial
→ Hasil: Tutorial React/Next.js
```

### Contoh 4: Full Combo
```
Search: "design"
Category: [DESIGN]
Tags: #ui, #ux
Date: [LAST MONTH]
→ Hasil: Design UI/UX bulan ini
```

---

## 9️⃣ NO RESULTS (Tidak Ada Hasil)

### Tampilan
```
┌─────────────────────────────────┐
│           404                   │
│                                 │
│      NO POSTS FOUND             │
│                                 │
│  Try adjusting your filters     │
│  or search query.               │
│                                 │
│  [CLEAR ALL FILTERS]            │
└─────────────────────────────────┘
```

### Solusi
1. Coba keyword lain
2. Kurangi filter
3. Klik `[CLEAR ALL FILTERS]` untuk reset
4. Cek spelling

---

## 🔟 CLEAR ALL (Reset Semua)

### Tombol
```
[✕ CLEAR ALL]
```

### Fungsi
- Reset search query
- Reset category ke [ALL]
- Remove semua tag selections
- Reset date range ke [ALL TIME]
- Kembali ke tampilan semua post

### Kapan Pakai?
- Setelah search selesai
- Mau mulai dari awal
- Hasil terlalu sedikit
- Filter terlalu banyak

## 💡 Tips & Tricks

### Tip 1: Start Simple
- Mulai dari search simple
- Tambah filter kalau perlu
- Jangan langsung pakai semua filter

### Tip 2: Combine Smart
- Search + 1 category = Hasil fokus
- Tags multiple = Hasil lebih banyak
- Date + category = Tren terkini

### Tip 3: Use Tags
- Tags paling spesifik
- Bisa multiple selection
- Remove individual tag dengan [X]

### Tip 4: Clear Often
- Klik CLEAR ALL setelah selesai
- Mulai fresh untuk search baru
- Avoid filter confusion

## 🐛 Troubleshooting

### Problem: No results
**Solution**: 
- Clear all filters
- Coba keyword lain
- Cek spelling

### Problem: Too many results
**Solution**: 
- Tambah filter
- Pakai search query
- Select specific tags

### Problem: Filter tidak kerja
**Solution**: 
- Refresh page
- Clear browser cache
- Cek console log

## 📊 Filter Priority

### Order of Filtering
1. **Category** → Filter by category first
2. **Search** → Filter by search query
3. **Tags** → Filter by selected tags
4. **Date** → Filter by date range

### Logic
- Filters are **AND** (semua harus match)
- Tags are **OR** (salah satu match)
- Search is **OR** (title OR description OR tags)
