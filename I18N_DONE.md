## 🎮 HOW TO USE

### **Language Toggle Location:**
```
Navbar (top right): [🌐] [ID] [EN]
                         ^^^^^^^^
                    Click to switch!
```

### **User Experience:**
1. User opens website → Default: **Indonesian**
2. Click **[EN]** → All text changes to **English**
3. Click **[ID]** → All text back to **Indonesian**
4. Refresh page → Language **persists** ✓

## 📝 HOW TO EDIT TRANSLATIONS

### **File to Edit:**
```
lib/i18n.tsx
```

### **Quick Edit:**
1. Open `lib/i18n.tsx`
2. Find translation key (e.g., `'hero.title.line1'`)
3. Edit value in:
   - Indonesian section (line 17-130)
   - English section (line 132-260)
4. Save → Auto reload!

### **Example:**
```typescript
// Indonesian
'hero.title.line1': 'UI/UX &',
'hero.description': 'Design yang bikin brand kamu stand out...',

// English
'hero.title.line1': 'UI/UX &',
'hero.description': 'Design that makes your brand stand out...',
```
