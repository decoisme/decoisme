---

## 🚀 How to Use

### Quick Search
1. Type keyword in search box
2. Results update instantly

### Advanced Filter
1. Click `[FILTERS]` button
2. Select date range / tags
3. Click `[CLEAR ALL]` to reset

### Combine Filters
```
Search: "tutorial" 
+ Category: [CODE]
+ Tags: #nextjs
+ Date: [LAST WEEK]
= Focused results!
```
