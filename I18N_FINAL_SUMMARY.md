## 💡 HOW IT WORKS

### **1. Provider Wraps App:**
```tsx
// app/layout.tsx
<I18nProvider>
  {children}
</I18nProvider>
```

### **2. Components Use Hook:**
```tsx
// Any component
import { useI18n } from '@/lib/i18n';

export function MyComponent() {
  const { t } = useI18n();
  
  return <h1>{t('hero.title.line1')}</h1>;
}
```

### **3. User Clicks Toggle:**
```
[ID] clicked → language = 'id'
            → localStorage.setItem('language', 'id')
            → All components re-render with ID text
```

### **4. Page Refresh:**
```
Load page → Check localStorage
          → Restore saved language
          → Render with correct language
```
