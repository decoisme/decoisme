## 🚀 Quick Start

### **First Time Setup**
```bash
1. Run SQL script: SETUP_TESTIMONIALS_SUPABASE.sql
2. Verify: SELECT * FROM testimonials;
3. Test: npm run dev
4. Open: http://localhost:3000/#testimonials
```

### **Daily Usage**
```bash
1. Login: https://supabase.com
2. Table Editor → testimonials
3. Edit → Save
4. Refresh browser
```
